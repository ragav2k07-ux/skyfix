Predictive maintenance

Know before an engine fails.

SkyFix reads aircraft engine sensor data, predicts how many flights each engine has left, and helps you book repairs before anything breaks.

See how it worksOpen the fleetTry your own data

Each dot is one engine, two per aircraft. Closer to the centre means closer to repair.

The problem

When an engine fails during service, the aircraft is grounded, passengers are stranded and repairs cost a lot. Repairing on a fixed calendar wastes parts on healthy engines.

The idea

Engine sensors change slowly as parts wear out. SkyFix learns those changes from engines that failed before. Every aircraft has two engines, and each one gets its own prediction.

The result

Maintenance is planned in advance: the most urgent engines go first, spare parts are ready, and the aircraft is not surprised on the ramp.

Give input

There are four ways to get data into SkyFix. Pick the one that fits.

Option 1: Type the readings for one engine

Move the sliders to set the sensor readings and watch the prediction change at once. The numbers are in standard units: 0 means "like a healthy new engine", and the further from 0, the more the engine has worn.

This small model is trained inside your browser on the simulated engines. It shows the idea. The Python model trained on NASA data is the one to quote for accuracy.

Option 2: Upload a file

  1. Collect engine sensor readings (for the hackathon, the NASA C-MAPSS files).
  2. Run python train_rul.py (or use Option 3 below, which runs it for you). It trains the model and writes predictions.csv.
  3. Choose that file here. Every page then shows your data.

Option 3: Train the model on NASA files

Choose the three NASA C-MAPSS files for one subset. SkyFix runs train_rul.py on your computer, then every page shows the trained predictions.

Option 4: Live feed (real airline use)

      
In a real airline the data is not typed or uploaded by hand. After every flight, the aircraft's data recorder sends the engine readings to a database. SkyFix reads the new rows, updates each prediction and refreshes the fleet. For the hackathon, the file upload in Option 2 or the training in Option 3 plays the part of that database.
